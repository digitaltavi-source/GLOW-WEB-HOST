3 · Đăng ký file thật

Tối đa 8 MiB mỗi file. File được gắn với mission đã chọn; đăng ký file chưa phải phê duyệt chất lượng.

4 · Xác nhận bằng chứng đã xem

Chọn hồ sơ chứa kind, artifact_sha256, evidence_sha256, bindings và reviewed_result khi đánh giá capability. Các file tham chiếu phải đã được đăng ký.
